# ✈️ SkyTracker DB Manager

Учебный проект по сбору данных о воздушном пространстве в реальном времени с использованием публичных API и реляционной базы данных **PostgreSQL**. Проект разработан с использованием **Poetry** для управления зависимостями.

## 🧱 Архитектура проекта

Проект спроектирован по принципу разделения ответственности и разделен на независимые модули:

1. **`parser.py` (ETL-пайплайн)** — отвечает за сбор, очистку и загрузку данных:
   * Скачивает географические координаты стран через **Nominatim API** (OpenStreetMap).
   * Скачивает данные о текущих полетах со всего мира через **OpenSky API**.
   * Фильтрует массив самолетов, оставляя только выбранные целевые страны.
   * Безопасно сохраняет очищенные данные в таблицы PostgreSQL с защитой от дублирования (`ON CONFLICT`).
2. **`db_manager.py` (Аналитический модуль)** — содержит класс `DBManager`:
   * Занимается исключительно чтением данных из базы с помощью оптимизированных SQL-запросов (`SELECT`).
   * Не зависит от интернета и работает автономно на локальных данных.
3. **`main.py` (Главный диспетчер)** — координирует работу всего приложения: подключается к базе, запускает создание таблиц, ETL-процесс сбора и демонстрирует работу методов аналитики класса `DBManager`.

## 🗄️ Структура Базы Данных

В PostgreSQL автоматически создаются две связанные таблицы:
* **`countries`** — хранит уникальные названия стран (`PRIMARY KEY`), широту и долготу.
* **`aircrafts`** — хранит информацию о самолетах (автоматический `id`, `icao24`, очищенный `callsign`, страну и скорость `speed`).

## 🚀 Аналитические возможности класса DBManager

Все методы класса реализованы на чистом SQL через библиотеку `psycopg2` с соблюдением требований безопасности (защита от SQL-инъекций через параметризованные запросы):
* `get_all_aeroplanes()` — выгрузка полного списка воздушных судов.
* `get_avg_speed()` — агрегатный расчет средней скорости самолетов средствами СУБД (`SELECT AVG(speed)`).
* `get_aeroplanes_with_higher_speed()` — фильтрация самолетов, летящих быстрее среднего значения, с помощью вложенного SQL-подзапроса (Subquery).
* `get_aeroplane_with_keyword()` — регистронезависимый поиск самолетов по части позывного с помощью оператора `ILIKE` и шаблонизации `%keyword%`.
* `get_countries_and_aeroplanes_count()` — продвинутый отчет, объединяющий таблицы через `LEFT JOIN` и группирующий данные (`GROUP BY`), для вывода координат стран и точного количества самолетов над ними.

## 🛠️ Запуск проекта

1. Убедитесь, что у вас запущена СУБД PostgreSQL и в pgAdmin создана пустая база данных (например, `skytracker`).
2. Установите зависимости проекта через Poetry:
   ```bash
   poetry install
   ```
3. Пропишите ваши параметры подключения (пароль от PostgreSQL) в файле `main.py`.
4. Запустите главный файл:
   ```bash
   poetry run python src/main.py
   ```
